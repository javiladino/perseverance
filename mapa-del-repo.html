Las 5 piezas clave para conectar Percy

1. Un plugin propio

La “caja” donde va todo lo de Percy; se enchufa con openmct.install antes de arrancar. src/MCT.js:435

2. Una raíz en el menú

Una carpeta “Perseverance” en la barra lateral. src/api/objects/RootRegistry.js:62 (ejemplo: src/plugins/staticRootPlugin/plugin.js:54)

3. Un proveedor de objetos

Dice qué cosas hay dentro de esa carpeta: batería, temperatura, odómetro… src/api/objects/ObjectAPI.js:168 (ejemplo: staticRootPlugin/plugin.js:55)

4. Un tipo y su ficha de valores

“Sensor de Percy”, con su hora y su medida, para que la gráfica sepa qué poner en cada eje. src/api/types/TypeRegistry.js:59 · modelo: example/generator/GeneratorMetadataProvider.js:20

5. Un proveedor de telemetría

El que de verdad trae los números: el historial (request) y los datos en vivo (subscribe). src/api/telemetry/TelemetryAPI.js:167 · modelo: example/generator/GeneratorProvider.js:90 y :100

Cómo conectamos Percy

  1. Elegir la fuente de datos. Nuestra simulación 3D (src/rover.js) ya conoce la posición, velocidad y batería del rover. Ella será la “fuente”.
  2. Sacar los datos de la simulación. Hacer que emita cada segundo un mensaje con hora + valores (por ejemplo, por un WebSocket o un canal del navegador).
  3. Crear el plugin “Percy” con las 5 piezas: raíz, objetos (un objeto por sensor), tipo percy.telemetry con su ficha (hora = eje X, valor = eje Y) y proveedor de telemetría.
  4. El proveedor escucha la simulación: en subscribe reenvía cada mensaje nuevo; en request devuelve lo guardado del rango de tiempo pedido.
  5. Enchufarlo y arrancar: openmct.install(PercyPlugin()) y después openmct.start(). El orden importa: primero enchufar, luego arrancar.
  6. Montar la pantalla: en Open MCT, arrastrar “Batería de Percy” a una gráfica, tabla o a un panel de control.
export default function PercyPlugin() {
  return function install(openmct) {
    openmct.objects.addRoot({ namespace: 'percy', key: 'raiz' });
    openmct.objects.addProvider('percy', { get: (id) => /* objeto del sensor */ });
    openmct.types.addType('percy.telemetry', { name: 'Sensor de Percy' });
    openmct.telemetry.addProvider({
      supportsRequest:   (o) => o.type === 'percy.telemetry',
      supportsSubscribe: (o) => o.type === 'percy.telemetry',
      request:   (o, opciones) => /* historial */,
      subscribe: (o, avisar)   => /* datos en vivo; devuelve cómo cancelar */
    });
  };
}
